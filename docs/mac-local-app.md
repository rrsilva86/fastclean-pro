# FastClean Pro no Mac

Use estes atalhos:

- `Abrir FastClean Pro.command`: inicia o app local e abre no navegador.
- `Parar FastClean Pro.command`: encerra o app local.
- `Instalar FastClean Pro no login.command`: faz o app iniciar junto com o Mac.
- `Remover FastClean Pro do login.command`: remove o inicio automatico.

Endereco local do app:

http://localhost:3000/pt/dashboard

Os dados deste MVP ficam salvos no navegador/localStorage enquanto ainda nao conectamos o banco real.
